Step-by-Step Setup Guide

Follow these steps to import and run HDP 2.6.5 in VirtualBox.

1

Download File

Download HDP_2.6.5_virtualbox_180626.ova (15.01 GB) using one of the mirrors above.

2

Import Appliance

Open Oracle VirtualBox, click File ➔ Import Appliance, select the .ova file, and click Import.

3

Boot VM

Select the imported HDP_2.6.5 VM and click Start. Wait 3-5 minutes for Hadoop services to initialize.

4

Access Ambari

Open your browser and navigate to http://127.0.0.1:8080 to access the Hadoop management dashboard.
